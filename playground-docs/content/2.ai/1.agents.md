This documentation is made to be easy to read for AI coding agents.

## Read the documentation

| What                                                     | Where                                                     |
| -------------------------------------------------------- | --------------------------------------------------------- |
| An index of all pages                                    | `/llms.txt`                                               |
| All pages in one Markdown file                           | `/llms-full.txt`                                          |
| One page as Markdown                                     | `/raw/<page-path>.md`, for example `/raw/guide/layers.md` |
| An MCP server with the tools `list-pages` and `get-page` | `/mcp`                                                    |

Each page also has a **Copy page** button, which copies the page as Markdown.

## Work on the yuri4n.dev repository

The repository has an [`AGENTS.md`](https://github.com/yuri4n/yuri4n.dev/blob/main/AGENTS.md) file. It gives the commands, the code rules and the release process, for humans and for agents. An agent must get approval from a human before it publishes a release.
