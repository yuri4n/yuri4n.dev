---
title: ExDoc links
description: Elixir references in code become links.
---

The exdoc layer adds `elixir` to the syntax colors and turns references
into links. In an `elixir` code fence, `Enum.map/2` links to hexdocs.pm:

```elixir
# Enum.map/2 doubles every number.
Enum.map([1, 2, 3], fn x -> x * 2 end)
```

An inline chip links too: `Enum.map/2`. A repository path links to GitHub,
because the `exdoc` app config of this site sets `repo` and `pathTop`:
`layers/docs-exdoc/app/utils/api-links.ts`.

A bare standard library root such as `Enum` stays plain text: many of these
roots are ordinary English words.
